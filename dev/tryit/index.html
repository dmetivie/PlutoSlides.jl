Try it

Below is the example notebook, opened in slide mode[1]. Click inside it, then use the arrow keys; ⧉ Slide Mode leaves slide (or press escape or go to slide 0). The printed pdf version is there. The page might take a few seconds to load.

This is a static page

This is the notebook's HTML export: no Julia runs behind it. You can browse the slides, but the theme, font, color and logo controls do nothing here. To use them, run the notebook in Pluto: click Edit or run this notebook at the top of the page, or open example/notebook_test_doc.jl from the repository.

Note that the HTML version uses CairoMakie because WGLMakie does not render in static exports. The PDF export uses WGLMakie. It is just a matter of CairoMakie.activate!() vs WGLMakie.activate!() in the notebook, and you can switch between them.

Open it full page

The deck is shown as on a 1300 px wide screen, scaled down to fit this page. For the real size, open it full page.

Print it to PDF

You can print this example notebook to PDF, by clicking the printer button (🖨) at the bottom right of the deck.

The export opens in slide mode because the notebook uses slide_mode_button(start_in_slide_mode_html=true) (see Starting in slide mode).
